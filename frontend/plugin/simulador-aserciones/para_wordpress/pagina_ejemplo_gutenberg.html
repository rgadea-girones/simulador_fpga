Ejemplos Basicos

B1 - Req/Ack exacto a 2 ciclos

Objetivo: validar latencia fija con implicacion solapada.

assert property (@(posedge clk)
  disable iff(!rst_n)
  req |-> ##2 ack
);
B2 - Reset limpia salida al ciclo siguiente

Objetivo: comprobar comportamiento inmediatamente posterior al reset.

assert property (@(posedge clk)
  $rose(rst_n) |=> !error_flag
);

Ejemplos Intermedios

Uso de ventanas temporales y secuencias de varios eventos.

I1 - ACK dentro de una ventana de 1 a 3 ciclos 
assert property (@(posedge clk)
  disable iff(!rst_n)
  req |-> ##[1:3] ack
);
I2 - Inicio de transferencia seguido de done 
sequence start_to_done;
  $rose(start) ##[2:6] done;
endsequence

assert property (@(posedge clk)
  disable iff(!rst_n)
  start_to_done
);

Ejemplos Avanzados

A1 - first_match para primera respuesta valida 
assert property (@(posedge clk)
  disable iff(!rst_n)
  req |-> first_match(##[1:5] grant)
);
A2 - estabilidad de bus durante transaccion 
assert property (@(posedge clk)
  disable iff(!rst_n)
  valid |-> $stable(data) throughout ready[->1]
);
